Category, level, language, 15–120 min, online/in-person, tags 1–8, outcome 10–300ch.

Booking

pending → countered → awaiting-payment (15m) → scheduled → completed / declined / cancelled / expired.

3 distinct people, online, same language, exact tag↔want match, 1/3→2/3→3/3 consent.

Badge

Leaderboard

XP · Level

XP = sum badge XP. Level = floor(XP/200)+1. XP forever; points reset per window.
