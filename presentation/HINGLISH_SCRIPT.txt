--------------------------------------------------------------------------------
SLIDE 03 — SOLUTION
--------------------------------------------------------------------------------
"Solution — One place to publish, discover, agree and record. Points:

• Ek account = learner + teacher.
• Publish skill: title 5–90, category (Other included), outcome 10–300, tags 1–8 unique, duration 15–120, online/in-person, proof link.
• Discover: search title/description/tag/@username; filters category/language/offer/delivery; tabs Discover/Skill trades/Free; saved skills; learning-request posts.
• Arrange: free · direct swap (2 separate times, both confirm) · paid mentorship (demo credits, 100 start, hold 15 min, no purchase).
• Agree: request → accept/decline/counter time → scheduled; server checks conflicts; reschedule before attendance.
• Learn: chat (polling 3s, need accept), external meeting link (teacher), attendance both confirm, evidence 10–2000 (learner) + feedback (teacher), reviews 1–5 (5–700, one per booking).
• Motivate: 12 badges + XP + leaderboard windows.

Isolated demo workspaces — ye global marketplace nahi hai."

SLIDE 04 — KEY FEATURES (Implemented Only)
--------------------------------------------------------------------------------
"Key features — jo aaj kaam karta hai, points me:

01 Account & profile — 18+ check; password 10–128; 6-digit code 5 min, on-screen (no email/SMS); avatar 512KB; username 3–24 unique per workspace; languages, timezone, wants 1–10, socials; persona switch + 1-hour invite; logout.

02 Skill management — create/edit/pause/reuse; Other category; tag chips Enter/+; max 20 per user; soft delete (history stays), block if open booking/swap return/circle inviting/active.

03 Discovery — search skill+people (@); filters; saved skills.

04 Bookings — tabs incoming/sent/upcoming/completed/closed; counter-time; reschedule; attendance both needed; swap needs both lessons.

05 Trade Circles — rule: 3 distinct, online, same language, exact tag↔want, no blocked pair; 1/3→2/3→3/3 consent; then 3 bookings; withdraw cancels remaining.

06 Chat & records — 1 intro → accept; polling; 500 msgs/convo, 100 loaded; unread; meeting link; evidence+feedback; reviews.

07 Badges NEW — 12 badges, common/rare/epic, how to earn clearly shown (e.g., 3 teaches, 1 circle, 5★); XP sum, Level floor(XP/200)+1.

08 Leaderboard NEW — Weekly Mon-Sun UTC / Monthly / Last 7 days rolling; points: +40 completed (+15 trade +20 circle) +25 skill +50 5★ +2 msg cap20 +15 post; podium + table.

Jo nahi hai: AI, video, real money, escrow, moderation panel — openly batate hain."

SLIDE 05 — HOW WE DOING IT, TERMINOLOGY
--------------------------------------------------------------------------------
"How we do it + terminology — points:

How:
• Stack: Next.js 16, React 19, TypeScript; SQLite local / Postgres prod / In-memory on Vercel demo (ephemeral).
• One project frontend+API; DB transactions for bookings/credits/messages; advisory lock for demo.
• Polling 5s state, 3s chat; no WebSocket, no E2E encryption.
• Limits: posts 150, circles 30, bookings 250 per workspace; build/typecheck/tests pass.

Terminology:
• Skill listing — as above.
• Booking states — pending → countered → awaiting-payment (15m) → scheduled → completed / declined / cancelled / expired.
• Trade Circle — 3 people, 3 skills, 3 pairwise lessons, exact match, 3/3 consent.
• Badge — 12, earned by action, tier common/rare/epic, XP 40–250.
• XP/Level — XP sum badges; Level floor(XP/200)+1; XP forever, points per window.
• Leaderboard — 3 windows as above; sorted points → XP → name.
• Workspace — isolated seeded demo; shared via 1-hour link; not global.
• Credits — fictional integer (100 = 1 credit); no purchase/withdrawal.

Flow: Publish → Discover → Request → Agree → Learn → Record → Recognize."

--------------------------------------------------------------------------------
SLIDE 06 — INNOVATION & IMPACT
--------------------------------------------------------------------------------
"Innovation — points:

• Beyond perfect 2-way: 3-way loops se impossible swaps possible, rule-based exact match, no AI.
• Unanimous consent — 3/3 pe hi 3 bookings active, time-conflict checks.
• Proof beyond attendance — separate evidence + peer feedback → reviews.
• Motivation without money — clear how-to-earn badges + live windows.
• One codebase, seeded workspaces for parallel demo without real data.

Impact & benefits — points, demo only:

• Learner: exact outcome/language find karo; knowledge se pay karo jab possible; badges/minutes/reviews se visible progress.
• Teacher: ek skill se kai learners; recognition + leaderboard momentum; feedback se improve.
• Community: impossible swaps via loops; chat learning se juda; safe demo (isolated, fictional data, help & safety).
• Honest: platform recognition, not accredited cert; no real payments; no staffed moderation; workspace expiry.

Closing line: 'Share what you know, learn what you need, keep a record.' — yehi demonstrated capability hai, measured social impact ka claim nahi.
